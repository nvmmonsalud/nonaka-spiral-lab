Build the Spiral, Not the Answer

Does Nonaka & Takeuchi's SECI model still explain how organizations create knowledge when half the knowledge workers are agents? And can LLMs crack the "we know more than we can tell" problem?

01 · The thesis

Nonaka is more relevant than ever — but the spiral must be extended

Artificial intelligence introduces a fundamentally new object into the knowledge-creating company: tacit machine knowledge — knowledge machines hold that is hard to articulate, but that travels at software speed. That changes everything except the core job.

Question 1

Does SECI still explain?

Yes — but only in an extended, nine-movement form where every human mode has a machine counterpart.

Question 2

Can LLMs externalize tacit knowledge?

Partially. Machines elicit brilliantly but articulate unreliably — externalization must be hybrid, with humans as the arbiter of justification.

Question 3

What is ba when agents participate?

It is infrastructure: a governed, permission-aware shared context layer — a graph, an MCP server, a memory policy.

"The knowledge-creating company's role was always to provide the shared context in which different kinds of knowledge feed off each other. The AI age raises the stakes on context — and makes it engineerable."

02 · The theory

The SECI model: four modes of knowledge conversion

Built from Polanyi's "we can know more than we can tell" (1966) and Nonaka & Takeuchi's study of Japanese innovation (1995). Knowledge is created by converting between tacit and explicit knowledge.

The spiral

Each cycle escalates: individual → group → organization → inter-organization.

Ba

Shared context "in motion" — physical, virtual, mental — where knowledge acquires meaning.

Enabling conditions

Intention, autonomy, creative chaos, redundancy, requisite variety.

Known weak points

Gourlay's critique: thin empirics, the conversion metaphor, hard to falsify. Tsoukas: entanglement.

04 · The extension

Tacit machine knowledge adds five movements

Machines now "know more than they can tell" (Chatterji, Rock & Talamàs 2026, arXiv 2606.29227). Unlike human tacit knowledge, machine tacit knowledge is portable at software speed — a second spiral interleaved with the human one.

1 · Encoding

explicit human → tacit machine

Pre-training, fine-tuning, RAG ingestion on enterprise corpora.

2 · Embedding

tacit human → tacit machine

RLHF preference rankings, expert demonstrations, accept/reject of agent output.

3 · Extraction

tacit machine → explicit human

Generated recipes, code, memos, hypotheses humans inspect and test.

4 · Assimilation

tacit machine → tacit human

Developers internalizing agent-suggested patterns into personal skill.

5 · Machine transfer

tacit machine → tacit machine

Model distillation, agent memory sharing, API-portable capabilities.

The result

Nine movements, one spiral

Externalization is no longer the only bottleneck — machine knowledge becomes organizational without articulation, if shared context exists.

False externalization is the new failure mode of the spiral: a hallucination is machine output claiming explicit status without ground truth. Green milk was a context failure; hallucination is a truth failure. Both are fixed by the same mechanism — a shared, grounded, human-auditable context.

The synthesis

Five analytic themes

① AI is a participant, not a tool · ② Externalization bifurcates (fast but fallible) · ③ Internalization becomes measurable · ④ The Ba is now infrastructure · ⑤ Trust is the rate-limiter — belief is a governance property now.

06 · The design principle

SECI-as-architecture: build the spiral, not the answer

Current agentic KM products are search engines wearing a knowledge-creation costume. A system that respects the spiral is a closed loop over all nine movements:

1 · Truth-conditioned extraction

Every extracted claim cites its explicit source (Glean-style grounding). Hallucination becomes a detectable event, not an existential risk.

2 · Feedback as first-class substrate

Every accept/reject/correct/rate action returns to the model or memory layer. The system measurably learns your tacit preferences with use.

3 · Ba as governed infrastructure

A semantic layer (ontology, glossary, lineage) plus cross-agent memory — versioned, diffable, reviewable, revertible. Disposable agents, durable memory.

4 · Respect the knowledge classes

Stable, decision, operational, workstream, ephemeral — different lifecycles. Mixing them breeds synthetic folklore and knowledge ossification.

5 · Close the loop into practice

Don't stop at answering — generate tutoring, simulations, agent-executed tasks with review. Measure internalization by action traces, not retrieval logs.

6 · Middle manager → spiral engineer

Someone owns the spiral's rhythm: pairing the model's wild proposals with domain judgment, curating context, treating green milk as a knowledge event.

7 · Agent memory as a governed asset

Uninspectable memory is a liability. Governed, audited, shared memory is the machine-side crystallization of the firm's learning — portable, combinable, valuable.

The verdict

Build the spiral, not the answer

Judge the system by whether human and machine knowledge are measurably feeding each other in an accelerating, grounded, governed loop.

07 · Takeaways

What this means for practitioners

For KM leaders

Stop building document repositories. Build the shared context layer — governed graphs, lineage, freshness — because that is now the scarce resource.

For AI builders

Design closed loops, not answer machines: grounded extraction in, feedback substrate through, practice generation out. Human review is your highest-quality signal.

For researchers

The next frontier: measuring internalization by action traces, governing machine memory against synthetic folklore, and testing externalization against the Matsushita benchmark.

The Matsushita test: did the AI artifact preserve, distort, or fabricate the expert's tacit knowledge?

Every externalization technology inherits this question. The answer is almost always "distort, without validation" — and that is exactly why the human loop is not optional.
